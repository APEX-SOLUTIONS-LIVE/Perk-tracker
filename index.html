Getting started

  1. Import an Apple password export or enter your services manually.
  2. Confirm which accounts are currently active, plus your specific card or plan.
  3. Review perk ideas and mark which ones you are genuinely eligible for.
  4. Track redemption dates and save a portable backup.

Discover websites from Apple Passwords

Import the Passwords.csv file from your Apple Safari export. Do not upload the ZIP or CSV into a chat, website, or cloud service. This local file parses the CSV directly on your device; it does not keep login names or passwords.

If iOS exported a ZIP, extract it first in the Files app, then select only the CSV inside. Safari exports include some accounts that aren't memberships; review each result.

Portable backups

Account names, product names, benefit notes, and dates live in this browser's local storage. They are not synced between devices. Export a JSON backup to move or restore the tracker; export CSV for Numbers or Excel. Neither export contains passwords.

Import replaces existing tracker data. Keep backups private because account names and financial products are personal.

Erase local tracker data

Removes all accounts and benefits stored by this file in the current browser. It does not delete any Apple Passwords records or any exported file.

Security limitations

The page contains no remote scripts, but you should still open and run it only on a device you trust. An exported Apple password CSV is plaintext and can be exposed by backups, shared folders, or other apps. Delete it from Files (and Recently Deleted, if applicable) once done. Where possible, manually enter providers instead of creating a password export at all.

Benefit ideas are research prompts, not verified current entitlements. Confirm exact card names, membership status, and current terms directly with each provider.
